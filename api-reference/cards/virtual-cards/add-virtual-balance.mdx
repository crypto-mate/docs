---
title: "Add to virtual balance"
description: "Add a delta amount to the virtual balance of a card."
api: "POST /cards/virtual-cards/{cardId}/virtual-balance/add"
---

Adds a delta amount to the virtual balance of a card for a specific token, and returns the resulting balance. Unlike [Override virtual balance](/api-reference/cards/virtual-cards/override-virtual-balance), which sets an absolute value, this endpoint applies a relative change.

The operation is idempotent: retrying a request with the same `x-idempotency-key` returns the original result instead of applying the amount a second time. Requires an API key with access level 2 or higher.

## Path parameters

<ParamField path="cardId" type="string" required>
  Card identifier.
</ParamField>

## Headers

<ParamField header="x-idempotency-key" type="string" required>
  Unique key that makes the operation safe to retry. Reusing the same key returns the original result without applying the amount again. Requests with a missing or blank key are rejected.
</ParamField>

## Body

<ParamField body="amount" type="number" required>
  Amount to add. Must be greater than 0, with up to 9 integer digits and 2 decimal places.
</ParamField>

<ParamField body="token_address" type="string" required>
  Contract address of the token to credit.
</ParamField>

<ParamField body="blockchain" type="string" required>
  Blockchain of the token (e.g. `POLYGON`).
</ParamField>

## Response

<ResponseField name="blockchain" type="string">
  Blockchain of the token.
</ResponseField>

<ResponseField name="token_symbol" type="string">
  Symbol of the token (e.g. `USDT`).
</ResponseField>

<ResponseField name="token_address" type="string">
  Contract address of the token.
</ResponseField>

<ResponseField name="virtual_balance" type="number">
  Resulting virtual balance for the token after the amount is applied.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://api.cryptomate.me/cards/virtual-cards/card_6f1e2a30-4a3c-4b2e-9a1d-5e8c9b7a1f23/virtual-balance/add" \
  -H "x-api-key: $CRYPTOMATE_API_KEY" \
  -H "x-idempotency-key: 4f5b8c9d-1e2a-4b3c-9d8e-7f6a5b4c3d2e" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 100.00,
    "token_address": "0xc2132D05D31c914a87C6611C10748AEb04B58e8F",
    "blockchain": "POLYGON"
  }'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{

  "token_symbol": "USDT",
  "token_address": "0xc2132D05D31c914a87C6611C10748AEb04B58e8F",
  "virtual_balance": 350.00
}
```

```json 412 Missing Idempotency Key
{

```

</ResponseExample>
