---
title: "Get individual card mirror wallets"
description: "List the mirror wallet addresses of an individual card."
api: "GET /cards/individual-cards/{cardId}/mirror-wallets"
---

<Warning>
  **Send only the assets this address accepts.** A mirror wallet is provisioned for a specific set of assets on its blockchain — the ones listed in `tokens` — and credits nothing else. Which assets those are depends on the blockchain. Any other asset can land at the address and stay there: it is never credited to the card balance, nothing returns it automatically, and no endpoint recovers it. Check the asset and the blockchain before every transfer — a wrong one is not reversible from the API.
</Warning>

<Note>
  A deposit of an accepted asset at a mirror address is credited to the card balance, the same as a deposit at the address returned by [Get individual card top-up wallets](/api-reference/cards/individual-cards/get-individual-card-top-up-wallets).
</Note>

Returns the mirror wallets of the individual card: the additional inbound addresses it has on other blockchains, each of which funds the card balance. The card's main deposit address is not a mirror wallet and is not part of this list — it comes from [Get individual card top-up wallets](/api-reference/cards/individual-cards/get-individual-card-top-up-wallets). Requires an API key with access level 1 or higher.

A card that has no mirror wallet answers `200` with an empty list. A card holds at most one mirror wallet per blockchain, so with Solana and Stellar available the list has at most two entries.

Enterprise virtual cards have the same pair of endpoints — see [Get card mirror wallets](/api-reference/cards/virtual-cards/get-mirror-wallets).

## Path parameters

<ParamField path="cardId" type="string" required>
  Individual card identifier.
</ParamField>

## Response

Returns an array of mirror wallet objects.

<ResponseField name="address" type="string">
  Inbound address of the mirror wallet on its blockchain.
</ResponseField>

<ResponseField name="blockchain" type="string">
  Blockchain of the mirror wallet. `SOLANA` or `STELLAR`.
</ResponseField>

<ResponseField name="enabled" type="boolean">
  Whether the mirror wallet is receiving deposits. A new mirror wallet comes back `true`. A `false` means the address is not accepting deposits — do not send funds to it while it reads `false`. This is not a state you can change.
</ResponseField>

<ResponseField name="tokens" type="string[]">
  Symbols of the assets this address accepts and credits, in the order the platform provisions them. Which assets these are depends on the blockchain: a `STELLAR` mirror wallet accepts `USDC` and `USDT0`, a `SOLANA` one accepts `USDC`. Anything not in this list is not credited and cannot be recovered — see the warning above.
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.cryptomate.me/cards/individual-cards/card_6f1e2a30-4a3c-4b2e-9a1d-5e8c9b7a1f23/mirror-wallets" \
  -H "x-api-key: $CRYPTOMATE_API_KEY"
```

</RequestExample>
