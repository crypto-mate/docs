---
title: "Get individual card balance"
description: "Retrieve the available virtual balance loaded on a single individual card."
api: "GET /cards/individual-cards/{cardId}/balance"
---

Returns the available virtual balance currently loaded on a specific individual card. Requires an API key with access level 1 or higher.

## Path parameters

<ParamField path="cardId" type="string" required>
  Individual card identifier.
</ParamField>

## Response

<ResponseField name="available_credit" type="number">
  Available virtual balance currently loaded on the card, in USD.
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.cryptomate.me/cards/individual-cards/card_6f1e2a30-4a3c-4b2e-9a1d-5e8c9b7a1f23/balance" \
  -H "x-api-key: $CRYPTOMATE_API_KEY"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "available_credit": 150.75
}
```

</ResponseExample>
