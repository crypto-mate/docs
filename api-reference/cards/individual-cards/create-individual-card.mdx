---
title: "Create individual card"
description: "Create a new virtual card for an individual client."
api: "POST /cards/individual-cards/create"
---

Creates a new virtual card assigned to an individual client. Requires an API key with access level 2 or higher.

A client can hold at most **5 cards** at the same time. Every card that has not been cancelled counts toward that limit, whatever its status; cancelling a card is the only way to free a slot. Requests over the limit return `412` and create nothing. See [Individual cards](/products/individual-cards) for the full rule.

## Body

<ParamField body="client_id" type="string" required>
  ID of the individual client the card will be assigned to.
</ParamField>

<ParamField body="card_holder_name" type="string" required>
  Name printed on the card. Maximum 27 characters, letters and spaces only.
</ParamField>

<ParamField body="approval_method" type="string">
  Transaction approval method. Possible values: `TOPUP`, `WEBHOOK`.
</ParamField>

<ParamField body="daily_limit" type="number">
  Daily spending limit in USD.
</ParamField>

<ParamField body="weekly_limit" type="number">
  Weekly spending limit in USD.
</ParamField>

<ParamField body="monthly_limit" type="number">
  Monthly spending limit in USD.
</ParamField>

<ParamField body="per_transaction_limit" type="number">
  Maximum amount allowed for a single purchase in USD, fees included. Does not apply to ATM withdrawals.
</ParamField>

  Weekly spending limit in USD.

<RequestExample>

```bash cURL
curl -X POST "https://api.cryptomate.me/cards/individual-cards/create" \
  -H "x-api-key: $CRYPTOMATE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "client_id": "client_abc123",
    "card_holder_name": "John Doe",
    "approval_method": "TOPUP",
    "daily_limit": 100.00,
    "weekly_limit": 500.00,
    "monthly_limit": 2000.00,
    "per_transaction_limit": 50.00
  }'
```

</RequestExample>
