---
title: "Get limit frequencies"
description: "Retrieve available spending limit frequencies for individual cards."
api: "GET /cards/individual-cards/limit-frequencies"
---

Returns the list of spending limit frequency options available when creating or configuring an individual card. Requires an API key with access level 1 or higher.

## Response

Returns an array of limit frequency objects.

<ResponseField name="code" type="string">
  Frequency code to use in card creation requests.
</ResponseField>

<ResponseField name="description" type="string">
  Human-readable description of the frequency.
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.cryptomate.me/cards/individual-cards/limit-frequencies" \
  -H "x-api-key: $CRYPTOMATE_API_KEY"
```

</RequestExample>

<ResponseExample>

```json 200 OK
[
  {
    "code": "per30DayPeriod",
    "description": "Monthly (30 days)"
  },
  {
    "code": "perDay",
    "description": "Daily"
  }
]
```

</ResponseExample>
