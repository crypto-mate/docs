---
title: "Respond to 3DS authorization"
description: "Report the cardholder's decision for an Out-of-Band 3D Secure challenge."
api: "POST /cards/individual-cards/{cardId}/3ds-authorization"
---

Reports the cardholder's approve/deny decision for a 3D Secure challenge that was delivered to your webhook. Individual cards use Out-of-Band 3DS: when the cardholder attempts a purchase, CryptoMate forwards the challenge to your webhook so your app can prompt the cardholder, and you report their decision through this endpoint. The challenge expires after a short window, so report the decision promptly. Reporting the same challenge more than once is safe — repeating the same decision does not trigger a second authorization attempt, but reporting a different decision for an already-answered challenge is rejected. Requires an API key with access level 2 or higher.

## Path parameters

<ParamField path="cardId" type="string" required>
  Unique identifier of the individual card.
</ParamField>

## Body

<ParamField body="challenge_id" type="string" required>
  Identifier of the 3DS challenge being answered, taken from the webhook payload.
</ParamField>

<ParamField body="approve" type="boolean" required>
  Whether the cardholder approved (`true`) or denied (`false`) the challenge.
</ParamField>

## Response

<ResponseField name="challenge_id" type="string">
  Identifier of the 3DS challenge that was answered.
</ResponseField>

<ResponseField name="approve" type="boolean">
  Whether the cardholder approved the challenge.
</ResponseField>

<ResponseField name="status" type="string">
  Resulting state of the challenge. `ALREADY_PROCESSED` when this decision had already been reported and was not sent to the card issuer again.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://api.cryptomate.me/cards/individual-cards/icard_6f1e2a30-4a3c-4b2e-9a1d-5e8c9b7a1f23/3ds-authorization" \
  -H "x-api-key: $CRYPTOMATE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "challenge_id": "25e4988d-9303-4199-983f-e90cc7bf9832",
    "approve": true
  }'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "challenge_id": "25e4988d-9303-4199-983f-e90cc7bf9832",
  "approve": true,
  "status": "APPROVED"
}
```

```json 404 Not Found
{
  "code": "NOT_FOUND",
  "message": "3DS challenge 25e4988d-9303-4199-983f-e90cc7bf9832 was not found"
}
```

```json 412 Contradictory Decision
{
  "code": "CHALLENGE_DECISION_CONFLICT",
  "message": "3DS challenge 25e4988d-9303-4199-983f-e90cc7bf9832 was already answered with a different decision"
}
```

</ResponseExample>
