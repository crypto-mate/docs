---
title: "Get individual cards holding wallet"
description: "Retrieve the holding wallet address of the individual cards program for centralized funding."
api: "GET /cards/individual-cards/holding-wallet"
---

Retrieves the holding wallet of the individual cards program, used as a central pool to fund the program before distributing balance to each individual card. Requires an API key with access level 1 or higher.

## Response

<ResponseField name="id" type="string">
  Holding wallet identifier.
</ResponseField>

<ResponseField name="alias" type="string">
  Internal alias of the holding wallet.
</ResponseField>

<ResponseField name="address" type="string">
  Deposit address of the program's holding wallet.
</ResponseField>

<ResponseField name="blockchain" type="string">
  Blockchain network the address belongs to.
</ResponseField>

<ResponseField name="enabled" type="boolean">
  Whether the wallet is currently enabled to receive funds.
</ResponseField>

<ResponseField name="tokens" type="object">
  Map of supported token symbols to their contract addresses on `blockchain`.
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.cryptomate.me/cards/individual-cards/holding-wallet" \
  -H "x-api-key: $CRYPTOMATE_API_KEY"
```

</RequestExample>
