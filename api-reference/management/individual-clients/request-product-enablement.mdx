---
title: "Request product enablement"
description: "Request the enablement of a product for a client."
api: "POST /management/clients/individuals/{clientId}/products"
---

Requests the enablement of a product for a client, returning the resulting request status and any missing requirements. Submit the missing documents through [Complete product documentation](/api-reference/management/individual-clients/complete-product-documentation) and the missing data through [Update individual client](/api-reference/management/individual-clients/update-client), then advance the request with [Submit product enablement request](/api-reference/management/individual-clients/submit-product). Requires an API key with access level 3 or higher.

## Path parameters

<ParamField path="clientId" type="string" required>
  Unique identifier of the client.
</ParamField>

## Body

<ParamField body="subproduct" type="string" required>
  Product to enable. Possible values: `cards_individuals`, `ramps_cards`, `ramps_pix`.
</ParamField>

## Response

Returns the created product enablement request. See [List client products](/api-reference/management/individual-clients/list-products) for the full field list.

<RequestExample>

```bash cURL
curl -X POST "https://api.cryptomate.me/management/clients/individuals/4QWq1rQtjnLM0wMswTRY9AmM4XTvY4GG/products" \
  -H "x-api-key: $CRYPTOMATE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "subproduct": "cards_individuals"
  }'
```

</RequestExample>
